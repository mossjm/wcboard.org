# Content Editor Guide (PDF)

## What this is:
A professional, detailed how-to guide for the person who will maintain/update the website content. They are NOT technical — they don't know what Astro is and don't need to.

## Requirements:
- Professional PDF layout (clean, well-organized, printable)
- Written for a complete non-technical user
- NO jargon without explanation
- Step-by-step instructions with screenshots or clear descriptions
- Cover EVERY content update they might need to do

## Topics to cover:
1. **Overview** — What the website is built with (brief, non-scary), how content flows from files to website
2. **Getting set up** — What tools they need (GitHub account, text editor like VS Code), how to access the repo
3. **Editing existing pages** — Where to find content, how to edit text, what NOT to touch
4. **Adding/editing board members** — How to update names, photos, bios
5. **Adding/editing meetings & events** — How to add new meetings, remove past ones
6. **Adding/editing images** — Where images go, naming conventions, size recommendations
7. **Publishing changes** — How to commit and push (step-by-step), how Cloudflare auto-deploys
8. **Common tasks cheat sheet** — Quick reference for frequent updates
9. **Troubleshooting** — What to do if something breaks, who to contact
10. **Glossary** — Simple definitions of any terms used (repository, commit, deploy, etc.)

- Friendly, patient, encouraging
