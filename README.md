# Wisconsin Cranberry Board — wcboard.org

Official website for the Wisconsin Cranberry Board, the grower-led market order board supporting Wisconsin's cranberry industry since 1983.

## Tech Stack

- **Astro 5** — Static site generator
- **Tailwind CSS 4** — Utility-first styling
- **Static export** — Fast, deployable anywhere

## Development

```bash
npm install
npm run dev      # Start dev server at http://localhost:4321
npm run build    # Build static site to dist/
npm run preview  # Preview built site
```

## Pages

- **Home** — Hero, key stats, mission overview, pillars, quick links
- **About** — Mission, purpose, funding, history timeline, board members, staff
- **Grower Resources** — Assessment info, election process, industry links
- **Programs & Research** — 2025 funding, research areas, partnerships (UW, WCREF, USDA)
- **Consumers** — Fun facts, health benefits, redirect to wiscran.org
- **Contact** — Contact form, board office info, DATCP election contacts
